# 005. Box 3 como lente de evaluación

**Estado:** Tomada

## Contexto
El programa entregó una guía oficial del marco Three-Box Solution (Govindarajan). Ver `context/originals/`.

## Decisión
Clasificar cada componente en Box 1, 2 o 3 y usar esa clasificación para dar forma al MVP, al Big Idea y al infográfico.

## Clasificación acordada
- RentScore Seguro y Cobro Garantizado: Box 3 genuino.
- Depósito en Custodia: Box 1 disfrazado de Box 3.
- Score Híbrido con REDJUM: habilitador, no una apuesta por sí mismo.

## Consecuencias
El infográfico original se evaluó como insuficientemente Box 3 por el peso del marketplace. Se generó una versión ajustada.
