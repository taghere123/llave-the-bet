Barra de filtros del héroe: campos blancos de 46px sin radio y botón de 48px con `radius-sm`, sobre una foto oscurecida (aquí, banda `azul-900`). Los campos ocupan el espacio libre y se apilan en móvil.

**Comportamiento del portal.** Un select combinado "Departamento, distrito" y otro de estado ("Todos", Preventa, Construcción, Entrega inmediata). El resultado son tarjetas `PropertyCard`.

**Accesibilidad.** Sobre foto oscura el botón usa green-500 con texto ink (7.2:1). Cada campo lleva etiqueta visible o `aria-label`; el foco usa el anillo `focus`.

**El consumidor aporta** las opciones de cada select y la imagen de fondo con overlay de al menos 50% de opacidad.
