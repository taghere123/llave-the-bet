# Glosario

| Término | Significado |
| --- | --- |
| LLAVE / La Llave | Nombre de la iniciativa. Marca: "Hogares que abren oportunidades" |
| The Bet | Programa de innovación de Interbank, IFS e Interseguro, con apoyo de Amazon/AWS |
| RentScore | Evaluación objetiva del riesgo del inquilino con datos bancarios de Interbank y su autorización |
| RentScore Seguro | RentScore más un seguro de hogar de Interseguro (daños al inmueble y responsabilidad civil) con prima pagada por el inquilino. No reemplaza el depósito ni cubre impago |
| Cobro Garantizado | Nivel 2. Interbank paga la renta cada mes, asume el impago y descuenta una comisión mensual: 3% con score alto, 5% con medio. No disponible con score bajo |
| Renta Adelantada | Nivel 3. La renta de un contrato de 1 año en un solo desembolso, menos una comisión: 15% con score alto, 25% con medio. No disponible con score bajo |
| Préstamo a tasa cero | Modelo financiero de los niveles 2 y 3: Interbank da un préstamo de consumo a tasa cero y la comisión es la tasa de interés implícita (decisión 016) |
| Housing Graph | Repositorio de datos de comportamiento de vivienda, uso interno del grupo |
| Cuenta Arrendador | Cuenta existente de Interbank, reutilizada, donde el propietario recibe el alquiler |
| REDJUM | Registro de Deudores Judiciales Morosos del Poder Judicial (Ley 30201) |
| D. Leg. 1177 | Régimen de Promoción del Arrendamiento para Vivienda (2015). Crea FUA y RAV |
| FUA | Formulario Único de Arrendamiento |
| RAV | Registro Administrativo de Arrendamiento para Vivienda |
| Box 1 / 2 / 3 | Marco Three-Box Solution: gestionar el presente, olvidar selectivamente el pasado, crear el futuro |
| AI-DLC | AI-Driven Development Lifecycle, metodología del taller de prototipos |
| Working Backwards | Metodología de Amazon centrada en el cliente, usada en el Taller 1 |
| Amazon Quick | Plataforma donde se ejecutaron las herramientas de ideación del Taller 1 |
| Crazy8 | Ejercicio de 8 ideas divergentes |
| SBS | Superintendencia de Banca, Seguros y AFP |
| MIPYME | Micro, pequeña y mediana empresa |
| Selección adversa | Solo se inscriben los riesgos más altos y la prima deja de ser sostenible |
